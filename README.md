# UnCiv Dragon Mod 🐉

**A majestic mod that adds dragons and a Dragon civilization to UnCiv!**

Created by the kind dragon with a saddle (and his rider).

## Features (planned)
- New Dragon civilization
- Flying dragon units
- Dragon-themed buildings and wonders
- Fire-related uniques and promotions
- Unique dragon leader

## Installation
1. Download / clone this repository
2. Place the folder into your UnCiv `mods` directory
3. Enable the mod in the game

## Structure
```
unciv-dragon-mod/
├── jsons/
│   ├── Nations.json
│   ├── Units.json
│   └── Buildings.json
├── Images/
```
